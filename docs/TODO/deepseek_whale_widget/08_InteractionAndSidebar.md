# 连续点按与设置页密度优化

## 问题

- 浮窗无参数点击 action 可以重复进入宿主 render 队列
- 已显示窗口被重复 `show()` 时会重复触发 render 请求
- 设置页使用全局大间距，并把每个设置项拆成独立列表节点，导致侧边栏信息密度过低

## 宿主通用优化

- 同一浮窗实例的无参数点击 action 同时只执行一个
- 带参数的输入、滑块和选择事件不通过点击单飞规则
- render 请求继续合并，已派发的 `onLoad` 不再重复执行
- 宿主不识别 Whale、Bubble、DeepSeek 或任何业务 action 名称

## 插件优化

- Whale 打开 Bubble 使用请求中状态
- Bubble 隐藏请求避免并发，台词点击增加最小间隔
- 设置页使用紧凑根间距
- 大小、透明度、吸附、音效、音量合并到一个设置区
- Token 统计和最近一轮合并到一个信息卡
- Token 输入和保存操作合并到一行

## 完成条件

- 连续点击不会形成无界 render/action 等待队列
- 所有原有浮窗设置和账户选择功能仍可用
- `src` 和 `dist` 内容一致
- 待执行设备上的连续点击和侧边栏截图验证
