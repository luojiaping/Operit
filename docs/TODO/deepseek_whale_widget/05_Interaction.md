# 触控与双浮窗改造

## 旧实现

鲸鱼和气泡由同一个正方形 Overlay 承载。宿主在每个触控事件中同步更新窗口位置、同步准备音效，并对整个窗口执行缩放动画。气泡 Canvas 使用窗口尺寸缩放，文字和点击节点使用固定尺寸。

## 修改意图

- 将鲸鱼和气泡拆成两个独立的 ToolPkg 浮窗
- 让气泡通过 `followWindowId` 锚定到鲸鱼，并在鲸鱼移动时同步位置
- 将拖动位置更新合并到 UI 帧边界
- 将短音效复制和加载移出触控主路径
- 用同一个尺寸比例更新两个窗口和气泡内部排版

## 验证标准

- 连续点击不触发同步音频解码和资源复制
- 拖动每帧最多提交一次窗口位置更新
- 气泡和鲸鱼不共享 Compose 点击节点
- 尺寸范围 `0.6x - 2.5x` 下图片、气泡、文字和 GIF 比例一致
- 隐藏鲸鱼时，跟随气泡同时销毁
